# 畫面的視覺元素（render）

- 第一階段（2026-10-23）：座椅、階梯、光線、從座位轉頭看。
- 第二輪（2026-10-24）：只留座位視角、倍數 0.5–4×、小地圖、球場地面、座椅混色、穹頂外殼、大螢幕。
- 官方票區（2026-10-24）：大巨蛋改用官方票區號；每排長度不同（被外框截短）；小地圖加 B1／L2 圖層切換，區的選單依樓層分組。
- 內部結構（2026-10-31）：
  - 人工草皮內野、壘包紅土方塊、內野白線。
  - 全壘打牆、黃色界外桿、打者之眼。
  - L2 外野與 L3–L5 的示意量體；牆頂調到 44 m。
  - 依據是網路資料（見 [venue-taipei-dome.md](venue-taipei-dome.md)）和使用者提供的內部全景照片。照片只做目視比較，不放進 repo、不描摹。
- 介面主題（2026-11-01）：「票根 × 記分板」，配色依場地切換。見下面「介面主題」。

所有元素都由本專案自己的資料或程式產生：座位位置、踏面、屋頂形狀來自 core，顏色與圖案由程式產生。沒有使用外部 3D 模型或貼圖，也沒有參考其他網站的畫面。顏色、牆高、螢幕位置有參考使用者自己拍的照片，但只做目視比較，照片不放進 repo。

等級的意思同 [venue-taipei-dome.md](venue-taipei-dome.md)：A = 規則或官方定義、B = 新聞報導、C = 本專案估算。

### 光線（第一階段，沒變）

- 半球光、上方平行光、three 內建的 RoomEnvironment，搭配 Neutral 色調映射。
- 不做陰影：室內燈光分散，單一光源的硬陰影反而不真實，而且 2.6 萬張椅子每次轉頭要多畫一遍。
- 不做霧：霧會讓遠處看起來比實際模糊，可能誤導遠座位的視野判斷。
- 屋頂邊緣的燈與亮著的螢幕用不受光的材質（MeshBasicMaterial），看起來是自己發光。

### 地面的畫法

- 地面七層幾乎同高，遠處的深度精度不夠會閃爍。第一版用 polygonOffset，結果把線條蓋掉了（線條不受 polygon offset 影響）。
- 改成：地板與平面地面圖層不寫深度、依 renderOrder 由下往上畫，而且比其他東西都早畫。場景裡沒有東西在地面以下，所以線條、看台、投手丘一定蓋在地面上。

## 操作

- **只有座位視角**：鳥瞰改成隱藏的除錯模式 `?debug=overview`（舊連結的 `mode=overview` 仍可用）；網址不再出現 `mode=`。
- **面板**：左上角，可收合（手機預設收合，展開後連同右上角的場地切換不超過畫面高度的 1/3）；排、號有 − / + 按鈕。
- **場地切換**：右上角的分段按鈕（棒球／演唱會）。
- **小地圖**：左下角，每一區是可點的形狀；點一區（或聚焦後按 Enter）跳到那一區的中央座位（排取中間、號取那一排的中間）。
- **轉頭**：拖曳轉頭（像抓著畫面移動）；鍵盤方向鍵每次 5°、`0` 回正；範圍左右 ±120°、上下 −45°～+60°。「回正」只重設方向，倍數不變。
- **倍數**：tan(fov/2) = tan(base/2) ÷ 倍數；1× = 垂直 50°（等效 26 mm）。

| 倍數 | 垂直 FOV（橫向畫面） | 說明 |
|---|---|---|
| 0.5×（預設） | 86.0° | 約等效 13 mm 廣角；直式 9:16 的垂直 FOV 是 117.8°，邊緣拉伸明顯 |
| 1× | 50.0° | 等效 26 mm |
| 人眼（1.7×） | 30.7° | C 級：約等效 44 mm 的標準鏡頭量級 |
| 4× | 13.3° | 上限 |

- 直式窄螢幕以水平 FOV 為基準，再套倍數，在比例 1 前後連續。
- 右下角顯示目前倍數與以「人眼」為基準的說明（「比肉眼看起來小、遠」等）。
- 資訊列的距離、俯角、水平偏角一律以正視焦點計算，轉頭與倍數只改變畫面。
- 畫面下方除了免責聲明，每個場館都多一句「畫面為示意，不代表尺寸準確。」（放在 UI，不放進場館資料：MCP 沒有畫面）。

## 已知限制

- **沒有走道、樓梯、出入口、柱子、包廂**：位置不知道，所以不畫。
- **遮擋只在畫面上**：二層懸挑、前排椅背、護欄的遮擋在畫面上看得到，但距離與角度數據沒有計算遮擋。
- **穹頂與螢幕是示意**：牆高、屋頂外形、螢幕的大小與位置都是依照片目視估計（C）。
- **演唱會的舞台與地面還是簡化的**：舞台仍是白色方塊，場地沒有地墊或舞台螢幕；還沒做鏡頭轉場。
- **線條只有 1 像素寬**：遠處的白線與格柵線會變細；照片裡的格柵是有寬度的鋼構。

## 擬真渲染（2026-11-01）

目標寫在 Claude Design 畫布的「渲染目標表」（含改版前截圖）。全部是 C 級目視估計，紋理由程式產生，不用外部貼圖或照片。

| 項目 | 做法 |
|---|---|
| 草皮 | polygon 的 `surface: "turf"`：程式產生的紋理，6 m 割草條紋（深的一條暗約 8%）加 ±3% 雜訊 |
| 紅土 | `surface: "dirt"`：4 m 一張的細顆粒，亮度 ±6% |
