# 敏感度分析：臺北大巨蛋 C 級參數

> 由 `npm run sensitivity`（`scripts/sensitivity.ts`）產生，**不要手改**。隨機種子 20261023，每次結果相同。

## 方法

- 擾動下表的 C 級參數：同時、獨立、在範圍內均勻抽樣，共 1000 次。
- **範圍本身也是 C 級假設**：它表示「估算可能差多少」，不是量測誤差。
- 每次都用 `buildTaipeiDome` 重建模型，並通過 `parseVenue` 驗證。
- 官方票區的排數（B）與每區寬度的規則保持不動；只擾動看台的距離與高度參數，每區寬度依規則重新推算。
- **B1 前緣距離與排距的上限由外框決定**：外框位置固定（C 級）時，B1 前緣距離超過 19 m 或排距超過 0.87 m，本壘後方就放不下官方的 38 排（B 級）。
  - 所以上限改用外框放得下的值（之前的範圍是 21.5 m、0.9 m）。如果真實值更大，代表外框位置也要跟著修正。
- 每排席數會隨距離重新計算，所以代表座位用「該排的同一比例位置」指定。
- 指標是 baseball layout 下 `getSeatView` 的 `metrics`（focus = 本壘板）。
- 水平偏角以基準值為中心展開，避免 ±180° 附近的跳號讓平均值失真。
- 被產生器拒絕的樣本（外框內放不下官方的排數、或隱含座位間距超出 0.45–0.65 m）：13 次。

## 為什麼是這個結果

### 1. 距離主要取決於「看台離本壘、離外野牆多遠」

看台是跟著球場畫的：本壘後方的弧以本壘為圓心，兩側的直線看台平行界外線，外野的弧跟外野牆同心。
所以座位到本壘的距離，幾乎就是「B1 前緣距離 + 排距 × 排數」（外野則是外野牆 + 外野淨空）。

- 本壘正後方 B1 第 1 排：B1 前緣距離擺動 4 m（15–19 m），距離擺動 3.92 m。
  - 95% 區間半寬 ±1.88 m。基準距離只有 18.6 m，相對誤差約 10.1%。
- L2 最後一排：它離 B1 前緣隔了 37 個排距，所以排距的誤差被放大 37 倍。
  - 排距擺動 0.07 m（0.8–0.87 m），距離擺動 2.25 m；B1 前緣距離擺動 3.47 m。
- 中外野（打者之眼旁）第 1 排：距離主要受外野淨空影響，擺動 3 m（2–5 m）時距離擺動 3.03 m。
  - 基準距離 124.6 m，相對誤差只有約 1.2%。

### 2. 俯角是「高度誤差 ÷ 距離」

俯角 = atan(高度差 ÷ 水平距離)，高度誤差 Δh 大約讓俯角變動 Δh ÷ 距離（弧度）。所以同樣的高度誤差，越近的座位影響越大。

- 本壘正後方 B1 第 1 排（18.6 m）：B1 內野 baseHeight 擺動 2 m（2–4 m），俯角擺動 6.05°。
  - B1 前緣距離改的是分母，前排距離短、比例變化大，所以也有 2.63°。
- 中外野第 1 排（124.6 m）：外野 baseHeight 同樣擺動 2 m（2–4 m），俯角只擺動 0.92°。
- L2 最後一排（57.0 m）：L2 baseHeight = B1 內野最後一排高度 + 淨空，所以 B1 的斜度誤差會累積 37 排再傳到 L2。
  - B1 內野 rowRise 擺動 0.1 m（0.3–0.4 m），俯角擺動 3.24°；L2 淨空擺動 1 m（2.5–3.5 m），俯角擺動 0.87°。

### 3. 水平偏角：只有側邊的座位受影響

水平偏角的變化 ≈ 側向位移 ÷ 距離（弧度）。本壘後方和外野的座位，參數改變時大多沿「離本壘的方向」移動，側向位移很小；一壘側的直線看台則是沿界外線的法線平移，每區的寬度也依外框重新分配，方位會跟著變。

- 本壘正後方的座位（113 區）：偏角只跟「中央座位是哪一席」有關。席數變成偶數時，最中間兩席各偏半個座位寬，所以 95% 區間是 0.00–0.86°。
- 一壘側（105 區）：B1 前緣距離改變時，座位沿界外線的法線方向平移、區的範圍也跟著重新切分，相對本壘的方位跟著變，擺幅 7.73°。
- 右外野（143 區，約 124.5 m）：外野淨空擺動 3 m（2–5 m），偏角只擺動 1.54°。

### 結論

- 對使用者最有感的「距離」，誤差主要來自兩個 C 級估算：B1 前緣距離（本壘後方距離，18.3 m）和外野淨空（3 m）。
- 越靠近本壘的座位，相對誤差越大：本壘正後方前排約 10.1%，中外野約 1.2%。
- L2 疊在 B1 上方，對排距和 B1 斜度特別敏感。
- 如果之後有可靠的資料，最值得優先校正的是：本壘到後擋網的距離、排距、B1 斜度。
